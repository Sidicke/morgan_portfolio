# Portfolio Professionnel — Morgan Bocovo

> **Entrepreneur & Conseiller en Projets d'Approvisionnement & d'Importation (Chine / France ➔ Bénin)**

Portfolio moderne, éditorial et performant conçu pour mettre en valeur les expertises, l'expérience terrain et les solutions d'import-export sécurisées de **Morgan Bocovo**.

---

## 💎 Direction Artistique & Identité Visuelle

- **Palette chromatique :** 
  - Ivoire éditorial (`#F6F4EF`) & Blanc chaud (`#FFFEFB`)
  - Vert profond impérial (`#173E3F`)
  - Cuivre chaud (`#A65C37` / `#D48B5D`)
  - Anthracite encre (`#19272A`)
- **Typographie :**
  - Manrope (Titres & Chiffres forts)
  - DM Sans (Corps de texte & ergonomie de lecture)
  - Cormorant Garamond (Accents italiques éditoriaux)
- **Monogramme & Favicon :**
  - Identité vectorielle sur-mesure (Squircle émeraude + monogramme ivoire & cuivre) aux formats SVG, ICO multi-résolutions et Apple Touch Icon Retina.

---

## 🚀 Fonctionnalités & Sections

1. **Header Fixe & Épuré :** Navigation fluide avec détection de la section active et soulignement animé cuivré.
2. **Hero Section :** Valorisation du portrait de Morgan Bocovo avec composition équilibrée et boutons d'action rapide (WhatsApp & Services).
3. **À Propos :** Philosophie d'intervention basée sur 3 principes d'action concrets (*Vérifier avant d'engager*, *Anticiper les risques*, *Agir sur le terrain*).
4. **Services & Accompagnement :**
   - Sourcing & Audit fournisseurs (Chine & France / 1688 / Alibaba)
   - Sécurisation des paiements (Alipay, WeChat Pay)
   - Logistique & Transit (Fret maritime & aérien vers Cotonou)
   - Conseil & Faisabilité économique
5. **Parcours :** Timeline narrative verticale interactive connectée au défilement.
6. **Réalisations & Cas d'Étude :** Schéma logistique Chine ➔ Cotonou et métriques réelles (jusqu'à −35 % sur les coûts d'achat négociés, 100 % conformes, 0 perte financière).
7. **Contact Direct :** Coordonnées directes (WhatsApp, E-mail direct, TikTok officiel) et formulaire compact avec validation accessible `aria-live`.
8. **Pied de page :** Minimaliste et soigné avec copyright et bouton de retour en haut de page.

## 🛠️ Stack Technique

- **Framework :** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styles :** [Tailwind CSS](https://tailwindcss.com/)
- **Animations :** [Framer Motion](https://www.framer.com/motion/)
- **Icônes :** [Lucide React](https://lucide.dev/)
- **Langage :** TypeScript

## 📦 Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/Sidicke/morgan_portfolio.git
cd morgan_portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour la production
npm run build

# Démarrer le serveur de production
npm run start
```
